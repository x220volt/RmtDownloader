🔍 테라박스 계정 쿠키(ndus) 값 알아내는 방법
방법 1. 개발자 도구 애플리케이션 탭에서 확인 (추천)
  1. PC 브라우저(Chrome, Edge 등)에서 terabox.com 에 접속하여 로그인합니다.
  2. 키보드 F12 키를 눌러 개발자 도구를 엽니다. (또는 우클릭 ➔ 검사)
  3. 상단 탭에서 애플리케이션(Application)을 선택합니다. (Edge는 '응용 프로그램')
  4. 왼쪽 사이드바의 저장용량(스토리지) ➔ 쿠키(Cookies) ➔ https://www.terabox.com 을 클릭합니다.
  5. 우측 쿠키 목록에서 이름(Name)이 ndus 인 항목을 찾아, 값(Value)을 더블 클릭해 복사합니다.
  6. 복사한 값을 위 TeraBox 계정 쿠키 입력창에 붙여넣고 설정을 저장합니다.
방법 2. 콘솔(Console) 창에서 1줄 스크립트로 즉시 확인
  1. terabox.com 로그인 상태에서 F12 ➔ 콘솔(Console) 탭을 클릭합니다.
  2. 아래 코드를 복사하여 콘솔창에 입력 후 Enter를 누릅니다:
    document.cookie.split('; ').find(r => r.startsWith('ndus='))?.split('=')[1]
  3. 화면에 출력된 따옴표 속 영문/숫자 문자열(예: YbKdYCKte...)을 복사하여 붙여넣습니다.
💡 팁: 개발자 도구의 Network 탭 등에서 ndus=...; ... 형태의 전체 쿠키 문자열을 복사해서 붙여넣어도 프로그램이 자동으로 ndus 값만 추출하여 적용합니다.

  1. 스마트폰 브라우저에서 현재 서버 주소(http://...)로 접속 후 로그인합니다.
  2. 아이폰 (사파리): 하단 중앙 [공유 버튼(네모+화살표)] ➔ 아래로 스크롤하여 [홈 화면에 추가] ➔ 우측 상단 [추가] 터치
  3. 안드로이드 (크롬 / 삼성 인터넷): 우측 메뉴(⋮ 또는 ≡) ➔ [홈 화면에 추가] 또는 [앱 설치] 터치
  4. 바탕화면에 생성된 원격 다운로더 앱 아이콘으로 언제든 원터치 접속하세요!
🌐 집 밖(LTE / 5G / 외부 Wi-Fi)에서 집 PC로 다운로드 보내기

외출 중에도 스마트폰에서 집 PC로 다운로드를 걸어두려면 아래 두 가지 방법 중 하나를 설정하세요:

  • 방법 A. Tailscale 무료 VPN (포트포워딩 불필요 · 가장 안전/간편): 집 PC와 스마트폰에 각각 무료 Tailscale 앱을 설치하고 같은 계정으로 로그인하면 PC 전용 고정 IP(예: 100.x.x.x)가 부여됩니다. 외부에서 http://100.x.x.x:7971로 접속하면 집 Wi-Fi와 100% 동일하게 작동합니다.
  • 방법 B. 공유기 포트포워딩 & DDNS: 공유기 설정(예: ipTIME 192.168.0.1)에서 외부 포트(예: 7971)를 서버 PC의 내부 IP·포트로 포트포워딩하고 DDNS 주소(예: http://myhome.iptime.org:7971)로 접속합니다.
💡 자동 주소 맞춤 팁: 외부 주소(Tailscale IP 또는 DDNS 주소)로 이 웹 대시보드에 접속한 상태에서 [📱 스마트폰 가이드] 탭을 열면, 단축어와 북마클릿 복사 주소도 해당 외부 주소로 자동 변환되어 생성됩니다!
